BITCOIN MINERS — STANDALONE HERO

Open index.html in Chrome/Edge, or serve this folder with any static web server.
Example: python -m http.server 8080
Then open http://localhost:8080

Includes the current hero, logo, miner parts, pedestal, decorative images,
scroll animation, responsive styles and fullscreen mobile navigation.
Keep the assets folder alongside index.html when copying or uploading.

Header/menu/CTA links are placeholders for the client to connect to their pages.
The remaining website sections are intentionally not included.
Google Fonts needs an internet connection; system fonts are the offline fallback.
Shared CSS is included in its original order to preserve the existing appearance.
The main website is independent of this folder; this folder can be deleted later.
